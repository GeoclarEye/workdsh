# deploy/docker/skills — GeoClar 技能

`../experts/` 那 14 个专家包的**对侧**：专家定义「我是谁、怎么做」，技能定义「这套工具**怎么调**」。两者都是导入包，都要人工导入一次。

| | 专家（`../experts/`） | 技能（本目录） |
|---|---|---|
| 回答什么 | 这个角色该产出什么、边界在哪 | 这组工具按什么顺序调、失败怎么办 |
| 怎么被使用 | 用户选中的角色 | 模型按 `name`/`description` 自行决定何时加载 |
| 格式 | `workdsh-expert` 包（带 manifest 摘要） | `SKILL.md`（+ 可选 `references/`、`scripts/`、`assets/`） |

## 这个技能治什么

一半来自真实调用日志，一半是对着门户「影像检索」页与各工具的出参逐条核过的口径：

- **先把位置变成范围**：平台**没有地名解析**。用户给文件或坐标就用它；只报地名时，助手可按自己的地理知识给近似范围，但**必须标注这是估的、并等用户确认**再动手 —— 一次检索会真的并发打多个数据源，估错整轮都偏。
- **调用顺序**：列数据集（这是**平台公开目录**，不是"该用户被授权的数据集"）→ 范围体检（`rules` 六条全 `pass=true` **且**可规整才算能直接检索；`pass=null` 是"本期无法判定"，不等于通过）→ 检索 → 大范围改用任务查询 → 要金额才调方案推荐。跳步会让后面的判断没有依据。
- **默认给一套方案，不是倒一张表**：无条件调用返回 12 套（`key` 只有英文码，技能里给了中文对照），以「性价比」为主推荐、附「最省 / 最清晰」对照，其余等追问。
- **覆盖率与金额各有唯一来源**：覆盖率只能取**该方案自己的** `coveragePercent`（取 `pool` 的恒得 100%）；金额只来自方案推荐工具，`pricingComplete=false` 时是下界、要说「≥」。
- **改条件只重算方案**：方案推荐每次都自己取候选池，不必重发检索；给了任一条件（云量 / 时相 / 预算 / 分辨率 / 侧摆角 / 数据集 / 同期一致）转 `custom`，返回 `CUSTOM` + `LATEST`/`SHARPEST`/`CHEAPEST` 三套**同池对照**，对照与 `CUSTOM` 可比。
- **失败后不要连发重试**：单次检索要并发问多个数据源，10~90 秒是正常的；重复调用只会把同一笔成本再付一遍，并让用户看到一串失败。正确反应是缩小范围或收紧条件。
- **区分三类失败**：全部工具同时报「无法确定调用者身份」是**连接器凭据**问题（凭据值需含认证方案前缀，如 `Bearer `）；单次超时是**没拿到结果**、不是没有影像；结果偏少可能是某个数据源整条不可用。
- **不臆造数字**：金额只来自方案推荐工具；它超时就如实说没取到，不要用单价乘面积推。
- **写明助手侧做不到的**：导出 SHP/KMZ、下单、地名解析、单景快视图与单价 —— 门户能做、本层没有工具，不承诺也不变通凑。

## 导入

技能与专家分两次导入，顺序无所谓，但**都要做**：

1. **先导入本技能**：WorkDSH →「专家 · 技能 · 连接器」→「技能」→ 导入 → 选 `geoclar-image-search.zip`（或直接选 `geoclar-image-search/SKILL.md`——导入框同时接受 `.zip` 与单个 `.md`）→ 预览后确认。
2. 再导入 `../experts/` 下的 14 个专家/专家团包。

## 依赖声明

那 14 个包里的每个专家（含专家团的成员与主理人）都声明了 `skillRequirements: [{ name: 'geoclar-image-search' }]`。这是**声明**不是硬门禁——技能是否真的用上，由模型按技能描述自行判断。声明集中在 `../experts/build-experts.mjs` 的 `expert()` 与 `build-teams.mjs` 的 `team()` 两处；要收窄到只挂部分专家，就从那里改成按专家传入。

改了本目录的 SKILL.md 之后重新打包：

```sh
cd apps/web/deploy/docker/skills
zip -r geoclar-image-search.zip geoclar-image-search/
```

导入器会校验包内的文件路径与大小（≤50 MiB、≤400 文件），技能包没有专家包那种 manifest 摘要，所以 `zip` 出来的包直接可用。
